# Furnishes 橘色 / 夕阳色商业化修订

> 调色板说明（2026-10-20 晚）：本文件记录的亮橘 / 夕阳色方向已被“暖色 mono + 橘色主色”取代，现行令牌与实际对比度见 `spatial-validation.md`；此处保留为商业修订历史。

日期：2026-10-20。此修订替代上一版深绿、米白、Georgia 大标题的视觉方向；路由与业务边界不变。

## 品牌色

| 角色     | 色值              | 使用位置                                             |
| -------- | ----------------- | ---------------------------------------------------- |
| 品牌橘   | #E83200           | 供应合作强调线、插画呼应、品牌识别                   |
| 深橘     | #C92D00           | 字标、按钮、标题强调；用于小字号白字按钮以提高对比度 |
| 蜜桃底色 | #FFF2E5           | 页面主背景与路由过渡                                 |
| 暖杏色   | #FFDBB2 / #FFD898 | 供应合作区、次级按钮、内容分区                       |
| 日落金橘 | #FFB35D           | 首屏渐变中的视觉焦点                                 |
| 深棕     | #3B2118 / #462318 | 正文、底部项目转化区                                 |

大面积深绿与灰绿色插画已替换。渐变集中在首屏，详细页面保留稳定浅底，保证规格与项目内容可读。品牌橘不用于低对比度的细小正文；主要 CTA 使用更深的橘色。

## 商业化不是仅换色

1. 首屏明确提供家具选型、空间规划与项目成本讨论；主 CTA 直接进入商业项目咨询，次 CTA 查看家具系列。
2. 业务入口前移到首屏之后，商业家具排第一，其后为住宅家具、3D 空间规划。
3. 四步流程每一步明确交付物：brief、规格与参考报价清单、可视化布局、调整后的选型与项目报价。
4. 真实 BTO 案例保留，明确是方案阶段，不包装为商业工程交付或华桂业绩。
5. 华桂板块以采购信息面板呈现产品资料、规格/饰面/数量、逐项目确认的供货范围；不再用大面积装饰性中文牌匾。
6. 全站顶部统一“Get a project quote”，底部统一“Request a project consultation”；不承诺即时价格、固定交期或未核实的工程资历。

## 最新首页 outline

首屏（商业定位＋咨询＋产品入口） → 简短品牌条 → 三大业务入口（商业优先） → 四步流程及交付物 → 真实案例 → 华桂供应合作资料 → 项目咨询 CTA → 页脚。

## 字体方向

Archivo 非衬线承担 h1/h2/h3、正文、导航及按钮，标题 650 字重；取消标题的大面积 Georgia 斜体。Georgia 只保留在一条短品牌分隔语中，作为有限的风格点缀。最新测量见 typography.md。

## 动画与设备

保持两段有限 CSS 首屏动画，时长及 reduced-motion 行为不变，没有新加轮播或滚动劫持。所有十个公开页面共用夕阳色体系，继续使用 320–3840 CSS px 的响应式规则。截图和媒体偏好检查均使用静态/reduced-motion 模式。

## 发布边界

新版本源代码与文档同步至本机 demo-commercial-refresh。GitHub 是否已推送以实际 Git 远端状态为准；本地预览地址依赖运行中的服务，静态截图可长期审阅。
