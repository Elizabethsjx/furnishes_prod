# 字体使用报告 — 夕阳色商业版

日期：2026-10-20。本报告替代上一版 Georgia 主标题方案，依据用户要求强化商业表达。

## 当前结论

首页约 **1.6% 衬线 / 98.4% 非衬线**（去空白字符数）。桌面 1440px 的文字矩形面积也约 **1.6% / 98.4%**。标题、正文、导航与按钮均使用 Archivo；Georgia 只用于一条短品牌分隔语。该比例是当前页面文字的测量结果，不是预先设定的品牌配比。

视觉判断：650 字重的非衬线标题更直接，适合 B2B 服务、规格信息和询价引导；橘色标题强调与渐变提供品牌温度，减少对斜体衬线的依赖。大标题、短段落、较轻标签与边框形成层级，避免全页只靠粗体区分信息。

## 方法与边界

- 来源：qa/static-checks.json；脚本 scripts/verify-corporate-static.cjs。浏览器 Chrome，reduced-motion 模式，字体加载完成后采样。
- 遍历页面文本节点，排除 SVG、脚本、aria-hidden 与无布局矩形的文本；按 computed font-family 分类。字符数去除空白。
- 面积取 Range.getClientRects() 总和，不等于墨迹像素或整张页面占比；包含整页已布局文字，不仅首屏。
- 中文会使用系统字形 fallback，未进行逐字字体解析；字体与换行可能随系统变化。
- 上一版实测桌面约 19% / 81% 字符、66% / 34% 文字矩形面积；其原始数据保留在 qa/pre-sunset-static-checks.json，不能作为新版现状。

## 使用规范

| 角色             | 当前规范                                   |
| ---------------- | ------------------------------------------ |
| h1/h2/h3         | Archivo / Arial / sans-serif；650 字重     |
| 标题强调         | 非斜体深橘 #C92D00；与标题同字体           |
| 正文             | Archivo，16px；4K 基础 18px                |
| Lead             | 17px；4K 19px                              |
| 导航、按钮、表单 | 非衬线；输入 16px；主要按钮点击区至少 44px |
| 短品牌分隔语     | Georgia 斜体；仅此处使用衬线               |
| Space Mono       | 根布局保留声明，新首页实际使用为 0         |

没有增加字体下载。布局在 320–3840 CSS px 下静态验证，无横向溢出；没有将 Chrome viewport 验证声称为 iOS Safari 实机测试。
