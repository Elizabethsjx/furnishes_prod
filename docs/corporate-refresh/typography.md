# 字体使用与视觉平衡报告

日期：2026-10-20。比较原默认 Heritage 首页与本次企业首页；浏览器为本机 Chrome，动画关闭，页面加载字体后测量。

## 结论

沿用 Georgia 衬线标题、Archivo 非衬线正文。新首页桌面文字约 19% 为衬线、81% 为非衬线；按文字矩形面积，约 66% / 34%。原首页约 13% / 87% 字符占比，但矩形面积同样约 67% / 33%。因此正文变短、业务层级更清楚，同时保留原本由大衬线标题承担视觉重心的风格。

视觉判断：桌面为“衬线建立品牌气质，非衬线承载业务信息”，平衡良好；手机约 47% / 53% 矩形面积，信息阅读更均衡；4K 约 71% / 29%，品牌标题更突出，但内容宽度被限制，正文不会横向拉长。这里不把主观视觉平衡伪装成一个客观评分。

## 测量方法及边界

- 脚本：`scripts/verify-corporate-static.cjs`；原始结果：`qa/static-checks.json`。
- 遍历页面根节点内文本节点，排除 script/style/SVG、aria-hidden 及无布局矩形的文本；按 computed font-family 分类。
- 字符数去除空白；面积用 Range.getClientRects() 的文字布局矩形相加，不是字体墨迹像素面积，也不是整张页面面积。
- 度量包括整页可布局内容，不限首屏；折叠菜单内容无矩形时不计入。静态字符分类主要对应英文字体声明，中文实际字形使用系统 fallback，未做逐字 glyph 字体解析。
- 各设备实际字体渲染、缩放、抗锯齿与系统中文字体会有差异。所有结果仅是本机 Chrome 对这些 CSS viewport 的测量，不是跨浏览器精确等值。
- 原页通过临时本地评审路由加载原组件；评审路由不进入交付代码。原商业版 CSS 主要为 Archivo，其颜色和无衬线标题不再作为新企业网站的默认规范。

## 字体角色

| 元素                             | 字体                              | 用途                                 |
| -------------------------------- | --------------------------------- | ------------------------------------ |
| h1 / h2 / h3                     | Georgia → Times New Roman → serif | 企业定位、区块标题、卡片标题         |
| em                               | Georgia 斜体、陶土色              | 控制在标题内的短语强调               |
| 正文 / 导航 / 按钮 / 表单 / 标签 | Archivo → Arial → sans-serif      | 功能信息与清晰阅读                   |
| 中文辅助说明                     | 当前字体栈的系统中文字形 fallback | 少量品牌表达；尚未统一跨平台中文字体 |
| Space Mono                       | 根布局仍声明，但新首页使用量为 0  | 保留给现有工作台，未新增等宽风格     |

## 尺寸与平衡

- h1：桌面流体尺寸，上限 5.7rem；手机约 2.65–3.9rem。
- h2：2.15–3.9rem；手机上限 2.8rem。
- 正文：16px；lead 17px；4K 基础 18px、lead 19px。
- 输入框继承 16px，避免 iPhone 对小字号输入的常见放大行为；仍需真机验证。
- 导航 13px、按钮 14px、辅助标签 10–12px；小标签只承载次级信息。
- 正文不使用衬线；没有新增字体下载。Archivo 已通过 next/font 载入，Georgia 使用系统字体。
- 若未来大量增加中文，建议统一指定合适的中文字体栈，并另行检查包体及换行；本轮没有引入大型中文字体文件。
